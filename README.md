# Music Funnel

Describe what you want to hear — AI finds it exactly.

A lightweight web app for discovering songs by description, lyric fragments, or similarity search. Also includes song identification via AudD.

## Features

- **Find Songs** — Describe mood, genre, scene, language, era, and more
- **Identify** — Hold to identify a song playing nearby (requires AudD API key)
- **Similarity search** — Find songs similar to any result
- **Share playlists** — Copy and share your curated lists

## Deploy

This is a static site. Deploy `index.html` and `manifest.json` to any static host (GitHub Pages, Netlify, Vercel, etc.).

For AI features outside Claude preview, configure a custom OpenAI-compatible API endpoint in Settings.
